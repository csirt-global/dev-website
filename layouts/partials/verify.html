{{/* The verification block. Deliberately shaped like a case record: the same key/value form this field uses to state verified fact about a vulnerability, turned on the organisation itself. On paper rather than ink, because the question it answers is "are you real", and a black panel is the wrong answer. Labels and notes are i18n keys, because they are the site talking. `value` is a literal fact and is never translated. `valueKey` is used instead where the value is a description rather than an identifier. */}}
{{ i18n "verify_title" }}

{{ with $row.label }}{{ i18n . }}{{ else }}{{ $row.literalLabel }}{{ end }} {{- if $row.url -}} {{ $value }} {{- else -}} {{ $value }} {{- end -}} {{- with $row.noteKey }} · {{ i18n . }}{{ end -}}
{{- end }}
